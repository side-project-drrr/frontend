    - 해결하지 못한 이슈가 있다면 함께 트러블 슈팅을 통해 해결해요.

2. 매주 함께 회고해요.

    - 매주 수요일 저녁에 주간 회고를 가져요.
    - 한 주 동안 세웠던 목표와 결과를 공유합니다.
    - 이에 대한 내용들을 노션에 기록하고 공유해요.

3. 각자의 의견을 존중하고, 조율해요.

    - 반대 의견도 자유롭게 내요
    - 정해진 의견은 그 때부터 팀의 의견이니 문제가 생겨도 팀원을 탓하지 않아요.

4. 이런 문화도 존재해요.
    - PR은 리뷰어가 코드 리뷰 후 수정한 후에 리뷰어가 머지할 수 있어요.
